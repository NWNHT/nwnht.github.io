Drivers?

Each line is one driver's points total over the trailing window of weekends, so a rising line means recent form rather than season standing. The rolling leader is not necessarily the championship leader — that disagreement is what the Champion match view highlights.

Constructors?

The same rolling window, totalled per team. Both cars can score in a weekend, so constructor totals run roughly double a single driver's, and rebrands are treated as one continuous team rather than starting fresh.
